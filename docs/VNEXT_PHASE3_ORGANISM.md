# DUMMY vNext Phase 3 forecast organism

Status: **COMPLETE_VALIDATED**

Phase 3 adds the first complete, deterministic vNext episode for two isolated
pilots: native `KXBTC15M` direction and `KXMLBGAME` pregame winner. The path is
shadow-only, consumes frozen outputs from the existing incumbent adapters, and
cannot replace the incumbent or reach live orders, promotion, or capital.

## Delivered capability

- Pure template routing resolves a supported market to exactly one specialist.
- Seven registered roles run through the Phase 2 contract and lifecycle layer:
  market prior, incumbent specialist, contrarian, calibrator, adversary, shadow
  controller, and synthesizer.
- Every provider and receipt timestamp must be explicitly verified. Evidence
  received after the decision clock is rejected.
- The market prior comes from a coherent two-sided frozen book. Paper
  execution requires witnessed, side-specific ask depth and uses the current
  taker-fee model; it never invents a fill.
- Three typed competing futures record assumptions, failure conditions, source
  family, and causal evidence.
- Adversarial dispersion, decomposed confidence, knowledge boundaries, and the
  expected value of additional analysis are stored in the synthesis message.
- Forecast and abstention are both durable typed protocol messages.
- The decision ID depends only on decision-time evidence. Later settlement and
  held-out replay inputs cannot alter the decision or execution record.
- Verified settlement grades every participating role. Calibration and trust
  changes remain unapplied proposals.
- Bounded template proposals replay only on distinct, verified held-out event
  clusters. Phase 3 always marks them not promotable because later vNext
  phases and their statistical gates are incomplete.
- All seven temporary agents retire immediately after issuance. The complete
  episode persists in an isolated, canonical, append-only JSONL ledger.

## Twenty-step episode

`issue_episode` accepts only decision-time evidence and records steps 1–13:
market detection, prior freeze, versioned world state, deterministic morphology,
point-in-time evidence, competing futures, adversarial attack, confidence,
knowledge boundary, stopping value, forecast or abstention, decision freeze,
and shadow execution. It returns a canonical `ISSUED` artifact that cannot
contain settlement, grades, replay, or promotion fields.

After the market closes, `complete_issued_episode` accepts that immutable
artifact plus separately verified settlement and held-out cases. It does not
rerun the organism. It completes steps 14–20: settlement, per-agent grading,
calibration/trust proposals, episode persistence, bounded improvement,
held-out replay, and a non-applying promotion-candidate record.

The artifact parser rejects a record if any step is absent, any participant is
not retired, shadow truth is relabeled as realized, broker contact or order
submission is asserted, the incumbent is substituted, or promotion is marked
automatic/eligible/applied.

## Deterministic replay and operation

`scripts/run_vnext_phase3_episode.py` exposes the actual two-stage lifecycle:

```powershell
python scripts/run_vnext_phase3_episode.py issue `
  --input C:\path\to\decision_time_input.json `
  --output C:\path\to\issued_episode.json

python scripts/run_vnext_phase3_episode.py complete `
  --issued C:\path\to\issued_episode.json `
  --truth C:\path\to\verified_later_truth.json `
  --ledger C:\path\to\vnext_episodes.jsonl
```

For an already frozen complete fixture, the `replay` subcommand runs the full
episode twice, requires byte-identical artifacts, and then appends it.

The command performs no market fetch, credential lookup, broker call, incumbent
weight mutation, or promotion. Malformed or noncausal input exits without
writing an episode.

The compact canonical template catalog is
`docs/VNEXT_PHASE3_TEMPLATE_CATALOG.json`. Full contracts are generated by
`phase3_template_manifest()` from `dummy.organisms.templates`.
